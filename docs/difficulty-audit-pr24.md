# PR #24 难度审计：练习题是否达到（或略高于）官方 DELF B1 / B2 水平

审计对象：`course/days/01–50.json`（B1）与 `course/b2/days/01–50.json`（B2）中的 reading / listening / writing（B2 另含 application 转述任务）。口语不在范围内。只做分析，未改动仓库其他文件。

## 0. 结论摘要

| 级别 · 技能 | 判断 | 把握 |
|---|---|---|
| B1 阅读 | **文本与题型：达到官方水平（at）**；**题目的实际区分度：略低于官方**（选项长度泄露，见 §3） | 中高 |
| B1 听力 | **略低于官方**（文本短约 15–25%、口语自发性标记只有官方的一半、全为三选一、干扰项不真实、选项长度泄露） | 中（没听录音） |
| B1 写作 | **达到官方水平，题面要求略高于官方**；范文处于 B1 档，个别 B1+ | 中高 |
| B2 阅读 | **文本与出题意图：达到、局部略高**（Ex1/Ex2 约 35–60% 的题干是立场、功能、词句含义类）；**但实际难度被选项长度泄露压到官方以下**（盲选最长项得分 93–94%） | 中高 |
| B2 听力 | **明显低于官方**（文档长度只有官方的约 35–65%，Ex3 三个短文档每个约 114 词，官方约 230–280 词；全为三选一，没有简答题） | 中（没听录音） |
| B2 写作 | **达到官方水平**；范文落在 B2 档，不是 B2+，虚拟式和让步结构偏少 | 中高 |
| B2 转述（application） | DELF B2 tout public 官方没有这一项，只能算补充练习；60–100 词的小任务，不能当作 DALF C1 synthèse 的替代 | 高 |

**总体判断：PR 把阅读和写作的篇幅、体裁、题量都拉回了官方量级，这一点基本到位。但“达到或略超官方”这个目标没有整体达成**，主要有三个原因：

1. 全部 3 选 1 题里，正确选项几乎总是最长的那个。这是一个机械性泄露，不是内容问题，却直接抵消了题目本身的难度。
2. 听力脚本偏短、偏书面，B2 听力差距最大。
3. 官方里有大量需要写出答案的题型（简答、V/F 加摘录、“用自己的话解释”），题库里完全没有，B2 全部是 MCQ。

## 3. 量化指标（全部题目，脚本统计）

统计范围：B1 阅读 1,650 题、听力 1,000 题；B2 阅读 1,150 题、听力 1,053 题。脚本在 `/tmp/claude-0/-home-user-delf50-web/75394115-0d7c-52cb-b73f-fd690e376425/scratchpad/` 下的 `stats.py`、`s2.py`、`s3.py`、`off.py`，未放入仓库。

### 3.1 最重要的发现：正确选项几乎总是最长的

在 3 选 1 题里，只考虑选项长度唯一最大的题，统计“正确答案就是最长项”的比例：

| 题库项目 | 比例 | 盲选最长项的预期得分 |
|---|---|---|
| B1 阅读 Ex2 / Ex3 | 76% / 80% | 76% / 78% |
| B1 听力 Ex1 / Ex2 / Ex3 | 75% / 80% / 79% | 74% / 78% / 79% |
| **B2 阅读 Ex1 / Ex2** | **93% / 95%** | **93% / 94%** |
| B2 听力 Ex1 / Ex2 / Ex3 | 79% / 79% / 76% | 78% / 79% / 75% |
| **官方 B1+B2 四套样题（n=96，解析略粗）** | **45%** | – |

随机基线是 33%。B2 阅读 Ex1 有 28/50 天、Ex2 有 32/50 天，正确项在 90% 以上的题里都是最长的。正确选项平均 69–71 个字符，干扰项只有 44–45 个字符。

另外，干扰项里含绝对化词（*toujours、jamais、aucun、seulement、uniquement、totalement、interdit*）的比例约为正确项的 3 倍（B2 阅读：16.2% 对 7.6%；B1 听力：9.6% 对 3.2%）。

也就是说，一个完全不看文章的学生用“选最长项”就能拿到 B2 阅读约 93% 的分数，而这套题的目的恰恰是让学习者面对官方难度。这是本审计里最高优先级的缺陷。

## 4. 定性分析（有引文）

阅读了约 185 道题的全文与选项，覆盖：B1 第 1、3、25、40、48 天的阅读与第 3、25 天的听力；B2 第 2、14、20、27、40、49 天的阅读或听力。

### 4.1 B1 阅读

- **文本达到官方水平。** R25-3 “Faut-il supprimer les notes à l’école ?” 约 400 词，有数字、反对意见、研究者立场、论点总结，和官方“locations saisonnières”（367 词）同量级。R48-3（可修复指数）有“数据对比、协会批评、制造商自评”，已经是 B1+。
- **Ex1 广告网格很接近官方。** R40-1 要求同时满足“儿童俱乐部、全包、海边、坐火车”四个条件，其中“坐火车”靠推断（“une navette gratuite vous attend à la gare de Royan”；科西嘉岛“n’étant pas reliée au continent par le rail”）。R01-1 里“Alliance des Langues 每季度 250 欧以内？”这道题的陷阱（学生才有 9 折，而题面设定你是来工作的）设计得好，**在或高于官方水平**。
- **但题目偏字面。** 我按题干启发式粗分：B1 Ex2/Ex3 里约 38% 是 V/F，46–50% 是细节题，只有 10–12% 是立场或推断题。R25-2 Q5 “Les élèves ont de meilleures notes” 的答案“Faux”直接对应原文 “restés identiques”，是反义词配对。R25-2 Q2 “La classe est annulée quand il fait mauvais temps” 对应 “qu’il pleuve ou qu’il vente”。这类 V/F **没有要求摘录**，比官方样题 2 的 V/F 加摘录简单。
- **典型干扰项不真实。** R25-2 Q1 “Ils font du sport dans la cour” / “Ils visitent une ferme” 都不是诱人的错项。R03-2 Q3 的 “retirer autant d’argent qu’on le souhaite”（对 “jusqu’à 150 euros”）是好的字面陷阱。
- **推断深度的上限偏低。** 较好的例子是 R03-2 Q8（市长认为志愿者有用但不能代替公共服务）和 R25-3 Q8（研究者的立场）。官方样题 2 的“C. Acceptable”（作者对口音的态度）和“sa grande capacité de travail”要求综合判断，题库同类题偏少。

### 4.2 B2 阅读

- **出题意图确实在对准 B2。** R27-2 Q5 问 “la courtoisie n’est pas une faveur que l’on accorde, c’est une position que l’on occupe” 的含义；R02-2 Q3 问 “Qu’on me comprenne bien” 的修辞功能；R14-2 Q8 问文末“桌子和椅子”意象；R40-1 Q8 问 “transformer un achat en rente”。这些**高于**官方样题的平均水平（官方 Ex1 里多数题是改写后的细节题，如“Les parents seraient plutôt partagés”）。
- **论坛 Ex3 达到官方水平。** R27-3 Q3 “Le maintien du service tel qu’il est n’est pas forcément souhaitable” 对 Killian 的 “Je ne suis pas certain que la maintenir dans ces conditions soit rendre service aux mères”，需要释义匹配，和官方 “Il est injuste de comparer…” 同类。
- **干扰项质量差，直接拉低实际难度。** R27-1 Q2 的干扰项 “Il ne peut traiter que les litiges de moins de cent euros”；Q3 的 “Elle avait perdu un procès”；Q4 的 “dommages et intérêts devant le tribunal”；R14-1 Q4 的 “Les infirmières ne souhaitent pas avoir d’enfants”；R14-2 Q8 的 “Les bureaux de vote manquent de mobilier”。这些在没读原文时就能排除。官方的干扰项是“似是而非”：同一篇文章里出现过、但归因或程度不对。
- **词汇难度。** 题库 B2 文章有一些罕见搭配，但句子较短（16.5 对官方 18–21），长词占比 13.4% 对官方约 19%。这意味着**信息密度略低于官方**，更像是“清楚的论说文”，没有官方那种数字、机构名和术语密集的新闻稿（如 Récylum 那篇）。
- **题型缺口。** 官方格式 B 的 “Expliquez avec vos propres mots l’objectif du principe de responsabilité élargie”（2 分）和 “V/F 加摘录”，题库一概没有。

### 4.3 听力

- **B1 听力 L25-2 / L25-3** 的格式正确（访谈、广播报道、2 遍），内容有让步和限制（“Ils ont raison sur les chiffres, mais pas sur le reste”），但脚本是**书面语**：整齐的完整句、没有重叠和自我修正、没有 “euh/ben/enfin”。L25-3 是一段连续的朗读式报道。官方 B1 听力里有 “Hmm, j’ai réfléchi mais…”、 “Moi, j’ai besoin de prendre mon temps…” 这样的真实说话痕迹。
- **B1 L25-2 的 Q1** 的三个选项是 “Tous les élèves, d’âges différents, sont dans la même classe.”、 “Elle n’accueille que des élèves de onze ans.”、 “Elle compte cinq enseignants.”：对的最长，两个错项都不诱人。
- **B1 L03-1（火车票改签）** 的 Q3 “Combien devra-t-elle payer ?”（18 / 30 / 12 欧）是需要实时抓数字的好题，但对应的 Q1、Q2、Q5 都是简单细节。
- **B2 L40-1（医疗之家）和 L49-2（学校合唱团）** 的话题和结构是 B2 水平：有对比、让步、隐含因果（“un projet qui repose sur une seule personne disparaît le jour où elle s’en va”）。但长度只有 370–395 词，而官方样题 1 的同类文档约 555–600 词，样题 2 的约 1,300 词。
- **B2 Ex3 明显偏易。** L40-3 的三个文档是“公交网络调整公告、手球俱乐部通知、慈善跑步”，每个约 110–130 词，内容是 A2–B1 的日常公告，题目是“公交会免费吗？”“去哪个城市？”这类事实题；干扰项如 “La gare routière fermera ses portes” 完全无关。官方样题 1 的 Ex3 文档主题是青少年刊物的变化、桌游的社会价值、情感机器人，题目要求归纳作者观点（“les nouveaux types de magazine vont… favoriser la réflexion sur l’actualité”）。**这里差距最大。**
- **答案可在播放速度下抓取吗？** 题库的题目顺序与文字稿顺序一致，每题对应一个独立句子，这一点与官方相同；因此难度主要取决于词汇和干扰项，而题库在这两项上都偏易。

### 4.4 写作

- **B1 题面**要求偏多。W05-2 在 160 词内要求“叙述晚会、承认打扰、说明已做的补救、提出一个补偿动作、谈邻里规则”五项；W35-2 要求“两个论点、一个例子、一个反对意见、结论”。**高于**官方（官方只要求给出观点和例子）。但没有给出需要回复的邮件，缺少官方的互动特征。
- **B1 范文**（W12 “Diego” 的回复、W35-2 “Réclamer n’est pas une perte de temps”）结构清晰、句子简单，**落在 B1 档**，在内容和组织上够 B1 满分，但不是 B1+（例如几乎没有 *dont*、虚拟式；每 1,000 词只有 1.1 个虚拟式）。
- **B2 题面** W20-1（市中心周末禁车，带 Nadine 的帖子）、W05-1（短途开车的原因）与官方的“contester une décision / justifier”同类，要求论证，达到官方水平。W35-1 要求“先写三段式提纲、写完按五步检查”，这是教学指令，不是考试要求。W50-1（给学习者的三条建议）更像个人经验分享，**论证要求低于官方**。
- **B2 范文**（W20-1、W05-1）：有 *d’autant plus que、autant… autant、comme si + imparfait、faute de*，B2 档合格。但每 1,000 词只有 1.7 个虚拟式、5.2 个让步结构、0.7 个 *dont*，B2+ 档的描述语（“tenir compte du point de vue du destinataire”、“variété”）体现不足。**属于 B2，不是 B2+。**

### 4.5 转述（application）

B2 的 application（如 A03-1 给祖母解释信息核实、A33-2 评论问卷数据）是 60–100 词的小任务，关键词检查（`keys`）只用来判断是否出现某些词。官方 DELF B2 tout public 没有此项。B1 的 application 是明显的模板（A10-1 到 A10-4 题面几乎相同，只替换主题），不在本次 PR 改动范围内，仅作观察。

## 5. 整体一致性

- **体裁模板固定。** B1 Ex1 在 50/50 天都是 4 则广告 × 4 条件；B1 听力 Ex3 在 49/50 天是 “Reportage radio”；B2 阅读三个练习在 50/50 天都是同一顺序的“文章 / 论说文 / 论坛”；B2 听力 Ex3 在 50/50 天是“三个短文档”。
- **难度没有爬坡。** 第 1–10 天和第 41–50 天比，句长、长词占比基本不变，每天词数增加约 6%。第 1–18 天标注为 “A1+→A2” 的语法阶段，配的阅读文章却是 B1+ 文本（第 3 天 R03-2 近 400 词，含 *indemnité*、*point relais*），没有过渡。这符合“直接对标官方”的目标，但需要产品上明确这是有意为之。
- **没有发现坏题或错键**，也没有“显然过于简单到可以忽略”的天数；但存在局部偏易的位置（B2 听力 Ex3 全部天数）。

## 7. 来源与局限

来源：见 §1 的 FEI 官方页面与 PDF 链接。样题是公开的 2 套 B1、2 套 B2 的 tout public 样卷，我没有看到更多真题。

局限：

1. **没有听录音。** 听力判断基于文字稿、录音时长和脚本中的口语标记计数；Piper 合成语音的清晰度、停顿和速度我无法评估，实际难度可能更高也可能更低。
2. **题目类型的粗分是启发式。** 我用题干关键词统计了“立场、推断类”的比例，再配合逐题阅读；约 185 题经过逐句核对，其余是脚本统计。
3. **官方对照样本小。** 官方词数、句长、长词占比来自 5–6 篇阅读文章和 4 份听力稿；听力稿词数含考试指令，比真实文档略高。官方“最长项”比例是解析 96 题得到的，解析对多行选项可能有偏差。
4. **词汇难度**用“9 字母以上词占比”和句长作为替代，没有使用法语词频表，不能反映稀有词。
5. **没有评估口语和 B1 的 application。**
6. 没有验证 PR 的前端逻辑，只读了数据。
